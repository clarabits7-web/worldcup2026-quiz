📱 아이패드에서 플레이하는 방법

같은 Wi-Fi 공유기에 연결되어 있으면 아이패드로 바로 즐길 수 있습니다.

STEP 1
Mac 터미널에서 로컬 서버 실행

터미널에서 아래 명령어 한 줄을 실행하면 웹 서버가 시작됩니다:

cd /Users/moon/Desktop/moon/develop/worldcup2026-quiz && python3 -m http.server 8080

또는 프로젝트 폴더 안의 start_ipad_server.sh를 더블클릭하세요.

STEP 2
아이패드 Safari 주소창에 아래 주소 입력
http://192.168.0.186:8080

아이패드에서 손가락 좌우 스와이프로 다음/이전 문제 넘기기도 지원합니다!

STEP 3
진짜 앱처럼 전체화면으로 사용하기 (꿀팁)

아이패드 Safari 하단/상단 공유 버튼(네모 화살표) ➔ [홈 화면에 추가]를 누르면, 아이패드 바탕화면에 전용 앱 아이콘이 생성되어 브라우저 주소창 없이 전체화면으로 쾌적하게 플레이할 수 있습니다.
